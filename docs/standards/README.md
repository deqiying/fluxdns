# 规范文档索引

本目录存放适用于多个模块或本地协作流程的可执行规范。项目级规则入口为仓库根目录的 [`AGENTS.md`](../../AGENTS.md)。

## 文档路由

- [文档维护规范](documentation-maintenance.md)：文档权威边界、目录选址、命名、索引、状态、同步、废弃和验证规则。
- [本地测试规范](local-testing.md)：本地配置目录、构建物 ignore、工具安装边界、DoH smoke test 和结果记录。

新增规范文档时，应使用清晰的英文文件名，补充本索引和根目录 `AGENTS.md` 的路由，并按[文档维护规范](documentation-maintenance.md)更新文档总索引或对应模块入口。
